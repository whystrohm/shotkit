# Shotkit project guidance

Read [the assistant and feedback direction](docs/assistant-feedback-direction.md)
when planning or changing assistant-facing behavior. It records Yuri's confirmed
requirements for chat, natural language, voice, recommendations, and learning from
explicit feedback across Shotkit and the board.

These are core product requirements. Keep client preferences scoped and inspectable.
Likes, editorial selections, critique verdicts, approvals, and publishing results are
distinct records. Preserve pinned production files and review provenance.

The direction document does not imply those features already exist. Its shared
event formats and model integration still need design and implementation.
