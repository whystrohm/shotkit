# Shotkit 3.2.0: The board, one command, and no setup

A first run now ends with a page open in the browser.

- **The board.** `sk board output/ --open` renders one page for the whole run: a contact sheet and a timeline of every shot, the critic's verdicts with their fixes, every prompt with a copy button, and each file checked against `run.json`. `--serve` runs it live and saves a frame dropped on a shot.
- **Copy for LLM.** The whole storyboard, one shot or the brand lock as Markdown.
- **`/shotkit`.** One command that plans the shots, writes the prompts and opens the board.
- **No setup.** The installer gives the validators a private Python environment. The `pip install` step is gone.
- **A starter brand** for briefs that name none, and a bundled finished run to look at.

Fixed: the installer's `pip` and `python` instructions failed on a stock Mac, and a brief with no brand was sent to a blank template the checks reject.
