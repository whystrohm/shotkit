# Shotkit 3.6.0: frames drawn from your brand, and files for the crew and the editor

- **Designed frames.** For a screen of your product, a number, a quote or a logo card, Shotkit draws the frame in code from your brand lock. No model, your colours and type, your exact words, and the same picture every time. `sk design output/`.
- **Proof it is the same.** `sk design output/ --check` draws every frame again and says if one changed. Run it on the computer that drew them: another operating system can set type a pixel differently.
- **The shoot and edit files.** `sk export output/ edit` writes a shot list in a crew's words, the on-screen text as timed subtitles, and an edit decision list for Premiere, Resolve and Final Cut.
- **The bundled example is now reproducible.** Every Brightdock frame comes from a card you can open and change.

Needs: Chrome, Edge, Brave or Chromium for designed frames. The shoot and edit files need nothing.
