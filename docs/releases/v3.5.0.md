# Shotkit 3.5.0: Stills, a deck and a rough cut

- **Export.** One button on a live board, or `sk export output/`. You get carousel stills with the text on them at the plan's size and 4:5, a PowerPoint deck with one slide per shot, and a rough-cut video with the text at its planned times.
- **The type on every file is the board's type.** The board draws each shot and the export tool photographs it, so nothing is redrawn by a second tool.
- **A new bundled example.** A 20-second software launch made from a team's own screens. `sk board --example` opens it.
- **`extrabold`** on-screen text weight.

Fixed: emphasised lines were drawn at 30% size in the open-shot panel; a check on your own photo could not pass, because it had to name a prompt.

Needs: Chrome, Edge, Brave or Chromium for the stills. `ffmpeg` for the rough cut. The deck needs nothing.
