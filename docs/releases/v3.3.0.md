# Shotkit 3.3.0: Frames and clips with your own fal.ai key

Shotkit can now make the frames and the clips.

- **`sk generate output/ --model flux`** shows the plan and spends nothing. Add `--yes` to send it. Stills go to `frames/round-N/`, clips to `clips/round-N/`, and clips play on the board.
- **Pick any model.** A generator name, or any fal model id. `--list` searches fal's models. It reads each model's published inputs, so new models work without a change.
- **Safe by default.** Nothing is sent without `--yes`, a reviewed frame is never replaced, and every request id is logged on submit.
- **Bring your own key.** Nothing ships with a key. A secrets check now runs in CI and fails the build if one is ever committed.
- **A new demo** in the README: the live board replaying a real run.

Fixed: type over a frame always fits and reads; copying no longer scrolls a phone; a live board keeps its place when it reloads.
