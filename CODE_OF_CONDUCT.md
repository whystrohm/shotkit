# Code of conduct

Be useful and be decent.

- Talk about the work, not the person.
- Assume the other person is acting in good faith, and ask before you conclude otherwise.
- No harassment, no insults, no discrimination. That holds in issues, pull requests and
  anywhere else this project is discussed.

A maintainer may edit or remove comments, close threads or block an account that breaks
this. To report a problem, write to [hello@whystrohm.com](mailto:hello@whystrohm.com).
Reports are read by the maintainer and kept private.
